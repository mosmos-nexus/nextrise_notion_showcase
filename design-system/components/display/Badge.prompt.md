Small pill label for statuses, categories, and markers like "베타 모집중".

```jsx
<Badge tone="primary" variant="soft">사전신청 진행중</Badge>
<Badge tone="success" dot>오픈 완료</Badge>
<Badge tone="secondary" variant="solid" size="sm">NEW</Badge>
```

`tone` maps to the brand/status palette. `variant`: `soft` (tinted, default), `solid`, `outline`. Optional `dot`.
