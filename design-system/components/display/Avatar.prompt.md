User or companion avatar — gradient-initials fallback, optional brand ring for a "Mos" companion.

```jsx
<Avatar name="민지" size={56} />
<Avatar src="/me.jpg" name="Jin" ring />
<Avatar name="Mos" shape="rounded" ring />
```

No `src` → gradient initials. `ring` wraps it in the Core→Light blue gradient frame. `shape`: circle / rounded / pill.
